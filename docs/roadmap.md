# Next validation work

Current supported styles, parameters and examples are in the [design guide](design.md).

1. Prototype measured-stock fit coupons and complete joints for the chosen style.
2. Select/test bolts, washers and any required creature clips; measure wear,
   stiffness and detached handling before committing full-size cuts.
3. Validate backing/installation loads and anchorage for the actual venue.
4. Compile/package ISF resources in actual Wire/Arena versions, relocate resources
   and test mapping/calibration on the assembled artwork.
5. Use actual front/side/oblique views and physical trials to judge new style and
   parameter combinations. Digital validity alone is not an aesthetic verdict.

These physical and host steps are NOT RUN. Broader topology, segmented backings,
continuous-motion proofs and a custom renderer are future work, not promised output.
