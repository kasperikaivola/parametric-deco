# Current decisions

- One schema-v2 style/parameters workflow, with laminar as the default artwork.
- Keep distinct layered-creature, radial-weave and rib-study algorithms for useful
  topology and construction variety; reject irrelevant or unknown controls.
- Python/build123d CAD, Shapely planar profiles, GLB scene interchange.
- Nominal 6 mm plywood, independent size requests and fixed manufacturing fit.
- Immutable manufactured definitions and physical instance identities; generation
  and inventory placement are separate modes. Old requests require explicit rewrite.
- One shared fabrication, preview and projection pipeline; ISF hosted by Wire and
  mapped once in Arena. No automatic host patch/preset claim.
- No default white paint. Grade and finish are optional.
- Digital geometry checks do not certify art, fit, structural loads or host runtime.

See [design guide](design.md) for parameters and tradeoffs. Superseded design and
review ledgers remain in Git history rather than the current documentation tree.
