# Laminar assembly — physical checks NOT RUN

Each anatomical plate is supported near both ends by direct through bolts on the
universal backplate grid. Straight rigid metal tubes fill the complete distance
from the common board to each plate. There are no unique board seats, trestles,
offset adapters or custom board drilling in this manufactured revision.

Use `mounting-evidence.json` for panel IDs, grid axes and span fractions, and
`mounting-hardware.json` for actual tube lengths. Fit washers and locking nuts;
choose commercial hardware and prototype fit, strength, locking and handling.
Physical strength, fit, preload, wear and detached handling are **NOT RUN**.

Assemble in a cradle. Install lower modules before overlapping higher modules
(reverse removal_order), keeping every tube captive on its bolt. Support the
entire plate before releasing its end clamps; remove bolts and lift in +Z.
Rear access requires detaching the board from its installation. Numerical motion
checks sample rigid translations and do not certify tools, fingers or deformations.

Projection resources still need real Wire/Arena/projector calibration and runtime
validation, which are **NOT RUN**. The dark common board remains behind all artwork
openings so that the same physical board can accept every compatible deco.
