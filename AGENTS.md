# Repository instructions

- Implement the approved plan inline.
- Perform only one review round, covering the complete implementation at the end.
- Do not run task-by-task reviews or dispatch task-by-task reviewers. This saves tokens.
- Run focused verification while implementing; tests are not review rounds.
- After the final review, fix material findings and verify the fixes without another review round.
- Keep manufactured inventory immutable. Leave report fields `physical_validation` and `host_validation` as `not_run` unless those checks were actually performed. Do not add disclaimer sentences about those checks to the UI, captions, warnings, or instructions.
